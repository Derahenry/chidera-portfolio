# Chidera Nwokolo, portfolio

Personal portfolio at **https://derahenry.github.io**.

Built with React, TypeScript, Vite, Tailwind CSS v4, Motion for React and Lucide icons.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run lint       # ESLint
npm run typecheck  # TypeScript
npm run build      # production build into dist/
```

## Deploy

Deployment is automatic. Every push to `main` runs `.github/workflows/deploy.yml`, which lints, builds and publishes `dist/` to GitHub Pages.

One time setup (already done for this repo): in the repo on GitHub, go to **Settings > Pages** and set **Source** to **GitHub Actions**.

The repo is named `Derahenry.github.io`, so the site is served from the domain root and `base` in `vite.config.ts` is `'/'`. If you move it to a repo with any other name, set `base` to `'/<repo-name>/'` and change the absolute URLs in `index.html`.

## Edit content

All content lives in `src/data`. Components only read from these files.

| File | What it holds |
| --- | --- |
| `src/data/profile.ts` | Name, contact details, CV path, nav links |
| `src/data/projects.ts` | Projects |
| `src/data/skills.ts` | Skill groups |
| `src/data/experience.ts` | Timeline |

### Add a project

1. Put any screenshots in `public/assets/` (keep them small, around 375 px wide for phone screens, JPG or WebP).
2. Add an object to the `projects` array in `src/data/projects.ts`:

```ts
{
  slug: 'my-app',                 // unique, used for ids
  name: 'My App',
  tagline: 'One line on what it is',
  period: 'January to March 2027',
  size: 'standard',               // 'featured' | 'standard' | 'compact'
  summary: 'Two or three plain sentences.',
  role: 'What I did.',
  tech: ['React', 'Supabase'],
  links: [
    { label: 'Try the live demo', href: 'https://...', kind: 'live' },
    { label: 'View the code', href: 'https://github.com/Derahenry/...', kind: 'repo' },
  ],
  media: { kind: 'screens', images: [{ src: '/assets/my-app-1.jpg', alt: 'Describe the screen' }] }, // optional
  facts: [{ value: '12', label: 'tests' }], // optional
}
```

`standard` cards take three fifths of a row and `compact` cards take two fifths, so pair one of each per row. Only a `featured` project shows the screenshot strip and the case study (`caseStudy`).

### Change the CV

Replace `public/assets/Chidera_Nwokolo_CV.pdf` with a file of the same name.

### Change colours or fonts

Design tokens are at the top of `src/index.css` (`@theme`). Fonts are loaded in `index.html`.

### Link preview image

`public/og-image.png` is generated by `npm run og` (`scripts/make-og.mjs`). Rerun it after changing the headline.
